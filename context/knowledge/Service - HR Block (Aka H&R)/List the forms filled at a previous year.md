
Use Case: See what forms filled in a previous year to check if you're filling correctly on this year (if similar financial situation)

Login into H&R and select the year, then open the Individual Tax Return:
![[Pasted image 20250414032801.png]]

A PDF opens. Open the sidebar bookmarks, and hopefully it’s spelled out for you. If they’re spelled out, drag and select for copy and paste
![[Pasted image 20250414032813.png]]

Then paste into a text file somewhere to look at what forms need to be filled when using 2023 as a baseline because of familiar financial situation

A benefit is you can easily CMD+F or CTRL+F on this text file to search up a form name (eg. 8995 when a line mentions to go to that form, so you can check if it was filled in a previous year, before spending much energy finding that page in the long PDF)
