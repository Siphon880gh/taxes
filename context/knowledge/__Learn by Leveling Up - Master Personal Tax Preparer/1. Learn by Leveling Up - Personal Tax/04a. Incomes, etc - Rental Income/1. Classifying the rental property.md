Form will ask for the home use type eg. Single Family Residence or Multi Family Residence

It's asked at Part I:
- 1a - Property A - Write in the rental property address
- 1b - Property A - Write in the code that corresponds to the property use type (Here this example, 2 for "Multi-Family Residence")
