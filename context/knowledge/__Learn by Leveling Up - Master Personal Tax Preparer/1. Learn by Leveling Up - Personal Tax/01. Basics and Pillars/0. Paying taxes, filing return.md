
**The IRS expects both:**  
- Pay taxes _as you earn income at every quarter even if the balance is 0 at irs.gov (UNLESS, your W2 employer is withholding income for you)_
- File a return _after the year ends_ to finalize what you owed vs. paid

**Important scenarios to remember:**
- **You can file a return and owe nothing** — e.g., if you had low income or lots of deductions.
- **You can file a return and get a refund** — e.g., if you had low income or lots of deductions.
- **You can owe taxes even if you don’t file** — e.g., self-employed income without paying estimated taxes.

Most people need to file a Form 1040. Even if you're not a W2 employee, you will still likely need to fill Form 1040.
